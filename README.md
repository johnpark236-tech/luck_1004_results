# 불멸 딜러 · 신화 피규어 추천 결과

스마트폰에서 영웅과 전투 목적을 선택하여 미리 계산된 추천 결과를 확인하는 페이지입니다. HTML을 다운로드하면 오프라인에서도 사용할 수 있습니다.

공개 파일은 추천 결과, 요약 설명, 적용 조건만 담습니다. 원본 영웅 스킬·스탯, 피규어 전체 옵션 표, 원본 이미지, DB·엑셀, 추천 계산 규칙은 이 저장소에 포함하지 않습니다.

웹페이지에 표시되는 추천 결과와 요약은 열람·복사할 수 있습니다. 이는 공개 분석 결과이며 실측 DPS 순위가 아닙니다. 원본 데이터나 계산 로직을 웹페이지에서 감추는 방식이 아니라, 공개 파일에서 제외하는 방식입니다.
